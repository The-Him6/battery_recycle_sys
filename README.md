# 绿源回收积分平台

基于 Spring Boot 3 + Vue 3 构建的废电池回收积分管理系统，支持用户提交回收订单、累计环保积分、兑换绿色商品及秒杀优惠券等功能。

| **MySQL 8.0** | 关系型数据库 |
| **Redis** | 登录态缓存、秒杀库存预扣 |

## 快速启动

### 1. 数据库

```sql
source backend/db/battery_recycle_system_1.sql
```

### 2. 后端

```bash
cd backend
mvn spring-boot:run
```

默认端口 `8080`，上下文路径 `/api`。

### 3. 前端

```bash
cd frontend
npm install
npm run dev
```

默认端口 `3000`，开发环境 `/api` 请求代理到 `localhost:8080`。

## 核心业务流程

### 一、回收流程

1. **用户提交回收订单**：选择电池种类与数量，系统按每类电池单价计算总数量和总积分，生成订单编号（`BR + 日期 + 用户标识 + 序号`）。
2. **明细暂存**：订单明细先以 JSON 形式暂存于订单的 `detailJson` 字段，订单初始状态为「待处理」。
3. **管理员处理**：管理员对订单进行状态流转（待处理 → 处理中 → 已完成）。
4. **完成结算**：订单变为「已完成」时，明细写入 `recycle_detail` 明细表，并自动为用户增加对应积分。
5. **取消订单**：用户仅可取消「待处理」状态的订单，取消后订单进入「已取消」终态。

> 说明：订单明细表只保留已完成订单的数据，未完成订单明细通过 `detailJson` 读取，保证统计口径一致。

### 二、积分兑换流程

1. **选择商品**：校验商品是否上架、库存是否充足。
2. **计算积分**：所需积分 = 商品积分单价 × 兑换数量。
3. **扣减积分**：扣除用户积分，积分不足则兑换失败。
4. **扣减库存**：扣减商品库存，库存不足则兑换失败。
5. **生成记录**：创建兑换记录，状态为「待发货」，同时写入兑换类型（积分兑换）。
6. **管理员发货**：管理员更新兑换状态（待发货 → 已发货）。

> 说明：使用秒杀券兑换商品走独立链路，不扣积分，兑换时自动核销对应秒杀券。

### 三、秒杀流程

1. **创建活动**：管理员创建秒杀活动（默认 500 积分、100 库存、草稿状态），设定活动时间与券的有效/过期时间。
2. **上架预热**：管理员上架活动时将库存预热到 Redis，作为秒杀预扣库存。
3. **用户抢券**：先做快速校验（活动已上架、在活动时间内、未重复抢购、积分充足）。
4. **原子扣减**：执行 Lua 脚本原子判断 Redis 库存与是否重复抢购，预扣库存并把用户加入已抢 Set，成功后投递消息到 RabbitMQ。
5. **异步发券**：消费者收到消息后，加用户级分布式锁（Redisson），扣减积分、累加已售数量、生成未使用的秒杀券（设定生效/过期时间），手动 ACK。
6. **失败补偿**：积分不足等业务失败直接补偿 Redis 预扣库存；系统异常进入重试，超过最大重试次数进入死信队列并补偿 Redis。
7. **用券兑换**：券到达生效时间后，用户可在有效期内用该券兑换商品（核销秒杀券）。

> 说明：秒杀采用「Redis 预扣 + RabbitMQ 异步落库」方案，Redis 保证高并发下的库存原子扣减，MySQL 事务兜底最终一致。
